# КОНТУР 0.1.0 — исправления и подготовка релиза

Дата: 24 сентября 2026. Unity 6000.3.6f1. Сцена: SampleScene.
Исходная механика одной комнаты и пяти этапов сохранена. Рабочее название
и оформление — «КОНТУР». Цель этой версии: законченная Windows-демоверсия.

## Доказательства

- `verification.txt`: 12 детерминированных проверок, включая три полных симуляции.
- `playmode-checks.txt`: 11 проверок реальной сцены, меню и взаимодействий.
- `scene-validation.txt`: обязательные ссылки, отсутствие Missing Script,
  единственный CameraController, четыре рычага с коллайдерами.
- `hover-checks.txt`: обе физические кнопки меняют и восстанавливают _BaseColor.
- `modal-input-check.txt`: открытое меню блокирует мышиные callbacks физических кнопок.
- `build-report.json`: Windows x64, Succeeded, 0 ошибок; единственное
  предупреждение — ожидаемое отключение Pipeline в Player.
- `player-smoke-result.txt`: отдельный exe запущен с Direct3D 12 на RTX 2060,
  процесс отвечает, ошибок загрузки/managed exceptions в журнале не найдено.
  Это проверка запуска, не прохождение всей игры в самостоятельном Player.
- `archive-check.txt`: ZIP содержит exe, данные, библиотеки, README и лицензию
  шрифта; SHA-256 записан в `SHA256SUMS.txt`.
- Полный непрерывный прогон через цели рычагов: победа, 75.80 с времени
  эксперимента, финальная нестабильность 73.07%. Ток, риск и таймер не
  подменялись; RPM последовательно 300/500/700/900/1000, поршни 75%, МПС 100%.
- Повторный прогон финальных исходников после оформления: Completed,
  75.78 с, риск 73.07% (`final-playthrough.txt`). Скриншоты 1920×1080
  сохранены в `screenshots`; краткая пауза из-за потери фокуса при проверке exe
  не сбрасывала и не подменяла состояние этого прогона.
- Детерминированные прогоны: 77.07–77.18 с с учётом выхода тока на первую цель,
  финальный риск 72.89–72.97%. Это проверка достижимости, а не оценка сложности
  для впервые пришедшего игрока.
- Инструкция и HUD проверены при настоящем размере Game View 1024×768;
  инструкция не имеет TMP-overflow. Также проверен 16:9.

## Что проверено и что этим не доказано

MCP использован для чтения/изменения сцены, компиляции, управления рычагами,
runtime-проверок и сборки. Автопрогон вызывает API рычагов, а не двигает мышь
человека. Он не заменяет внешний тест удобства первого знакомства.
Полноценная поддержка Linux/macOS/WebGL и геймпада не заявляется.
Минимальные аппаратные требования не устанавливались по одной машине.
Предупреждения Editor о VS UDP и Unity AI Account относятся к среде разработки.

## Следующие действия перед открытой публикацией

1. Распаковать готовый ZIP на отдельной Windows-машине и проверить запуск,
   звук, мышь/клавиатуру, fullscreen и одну полную смену.
2. Дать 2–3 новым игрокам пройти без подсказок автора. Записать время первого
   успешного запуска, причины аварий и понимание МЗС; менять баланс по фактам.
3. Подтвердить название, credits и происхождение исходных моделей/звуков
   из `THIRD-PARTY.md`. Уточнить автора и контакт для обратной связи.
4. Создать черновик itch.io по `itch-page.md`, приложить ZIP и настоящие снимки.
   Проверить скачивание черновика и только затем переключить видимость.

Публичная загрузка, публикация страницы и платёжные настройки в эту работу
не включались. Это подготовленная демоверсия, а не обещание отсутствия
любых возможных ошибок на всех системах.
